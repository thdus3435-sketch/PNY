## 7. 기업마당 상세 공고 화면

기업마당 원문 URL은 `X-Frame-Options: DENY` 때문에 iframe 미리보기에는 직접 표시되지 않습니다.

따라서 앱 화면에서는 아래 중 하나로 보입니다.

| 방식 | 표시 결과 |
|---|---|
| iframe 직접 표시 | `www.bizinfo.go.kr에서 연결을 거부했습니다.` |
| 새 탭에서 열기 | 정상 표시 |
| 시트 저장 데이터 렌더링 | 지원대상, 지원내용, 접수처, 문의처, 첨부파일 표시 가능 |
| Apps Script UrlFetchApp 프록시 | 원문 HTML 일부를 서버단에서 가져와 자체 HTML로 표시 가능 |
